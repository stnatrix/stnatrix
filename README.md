### Principles

- **Zero Bloat & Telemetry:** Full control over personal data and minimization of background telemetry.
- **Resource Discipline:** Strict memory bounds (`cgroups v2`), subprocess isolation, and single-responsibility architecture.
- **Self-Contained:** Self-hosted assets, local typography, and zero external tracking dependencies.
